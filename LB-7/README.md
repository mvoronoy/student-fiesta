# LB-7.  Fix Solid


## 1. Локальні зміни.

- Створити на вашому локальному диску вашу персональну теку (наприклад: `LB-7\MaxVoronoy`)
- Використайте вашу улюблену мову програмування для того, щоб виправити помилки у зразках, які порушують SOLID. 

## 2. Зміст роботи

Необхідно розглянути окремо кожний файл:
- [Літера S 01_S.py](./01_S.py)
- [Літера O 02_O.py](./02_O.py)
- [Літера L 03_L.py](./03_L.py)
- [Літера I 04_I.py](./04_I.py)
- [Літера D 05_D.py](./05_D.py)

Зрозумійте яким чином порушено принцип. Зробіть вашу власну реалізацію, яка правильно застосовує відповідний принцип.


## 3. Зробити зміни доступними для загалу

На цей момент ви маєте 5 файлів (`LB-7\MaxVoronoy\01_S.cpp` ... `LB-7\MaxVoronoy\05_D.cpp`) 

- За допомогою середовища зробіть commit всім файлам
Обов'язково опішить коментар, що зроблено.

- Перевірити актуальність вашого локального репозитарію  

Треба впевнитись, що ваші зміни не конфліктують з віддаленими, для цього ще раз виконуємо команду `pull` 
([дивись](../LB-1/README.md) лабу #1).

- Перемістити локальні зміни на віддалений репозитарій.
Спробувати виконати команду `push` (конфліктів, скоріш за все, не повинно бути).
