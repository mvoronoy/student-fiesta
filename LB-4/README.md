# UML. Навички створення Component діаграм


## 1. Локальні зміни.

- Створити на вашому локальному диску вашу персональну теку (наприклад: `LB-4\MaxVoronoy`)
- За допомогою правої мишки створить Plant-UML файл. Наприклад `LB-3\MaxVoronoy\components.puml`. Плагін одразу створює
певний зміст :

``` puml
@startuml
' все зайве тут можна прибрати
@enduml 
```

## 2. Зміст роботи
Створити UML Component diagram за мотивами вашої роботи по доставці піци або перетримки котиків.

### Що важливо показати

Деталі стрілок можна прочитати на сайті PlantUML: https://plantuml.com/component-diagram


## 3. Зробити зміни доступними для загалу

На цей момент ви маєте 1 новий файл (`LB-4\MaxVoronoy\components.puml`) 

- За допомогою середовища зробіть commit цьому файлу
Обов'язково опішить коментар, що зроблено.

- Перевірити актуальність вашого локального репозитарію  

Треба впевнитись, що ваші зміни не конфліктують з віддаленими, для цього ще раз виконуємо команду `pull` 
([дивись](../LB-1/README.md) лабу #1).

- Перемістити локальні зміни на віддалений репозитарій.
Спробувати виконати команду `push` (конфліктів, скоріш за все, не повинно бути).
