# LB-8. Базові алгоритми обробки даних.


## 1. Локальні зміни.

- Створити на вашому локальному диску вашу персональну теку (наприклад: `LB-8\MaxVoronoy`)
- Використайте вашу улюблену мову програмування для того, щоб створити 2 головні алгоритми для обробки даних.

1) Аналог операції `JOIN` / `UNION` / `NOT-IN` 
2) Аналог операції `GROUP BY`

## 2. Зміст роботи

Необхідно завантажити локально 2 CSV файли з публічних доступних даних компанії Airbnb:
- [Barcelona1.csv](./Barcelona1.csv)

Колонки:

|id|name|zipcode|smart_location|country|latitude|longitude|
|-|-|-|-|-|-|-|
|внутрішній ідентифікатор|назва|поштовий індекс|розташування|країна|географічна широта|географічна довгота|


- [Barcelona2.csv](./Barcelona2.csv)

Колонки:

|listing_url|name|zipcode|smart_location|country|latitude|longitude|
|-|-|-|-|-|-|-|
|посилання на джерело|назва|поштовий індекс|розташування|країна|географічна широта|географічна довгота|


Деякі дані з обох файлів співпадають, а деякі розбіжні. 

На вашій улюбленій мові программування завантажте в пам'ять обидва файли. Можете використовувати будь-яку доступну бібліотеку. 

### Операція `JOIN` / `UNION` / `NOT-IN`
>[!IMPORTANT]
> Для шанувальників Pandas та її аналогів строго заборонено використовувати вбудовані аналоги цих функцій!

Зробіть власну імплементацію яка поєднує обидва файли по `name`+`latitude`+`longitude` 

Тобто:
- `JOIN` - повинен повернути стрічки для двох файлів де ці 3 колонки співпадають.
- `UNION` - поверне будь яку стрічку яка існує в кожному файлі, але для тих де колонки співпадають результат буде лише згаданий 1 раз.
- `NOT-IN` - знайти ті стрічки 'Barcelona1.csv' яких нема в Barcelona2.csv 

### Операція `GROUP BY`
>[!IMPORTANT]
> Для шанувальників Pandas та її аналогів строго заборонено використовувати вбудований аналог цієї операції!
Працюємо лише з 'Barcelona1.csv'. Зробіть власну імплементацію `GROUP BY` яка для всіх `zipcode` друкує
які є `latitude`+`longitude`.

Питання яке треба відповісти (додайте як текстовий файл):
- Які ще колонки крім `zipcode`, `latitude`, `longitude` можна надрукувати в цій реалізації?
- Чи можна пришвидшити ваш алгорітм?
