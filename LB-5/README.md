# Design patterns


## 1. Локальні зміни.

- Створити на вашому локальному диску вашу персональну теку (наприклад: `LB-5\MaxVoronoy`)
- Використайте вашу улюблену мову програмування для створення вашого розуміння наступних шаблонів. 

## 2. Зміст роботи
Описати мовою програмування Creational Patterns Abstract Factory, Builder, Factory Method, Prototype and Singleton за мотивами вашої роботи по доставці піци або перетримки котиків.

Програма повинна пройти покроково створення замовлення та надрукувати остаточний результат.

## 3. Зробити зміни доступними для загалу

На цей момент ви маєте 1 новий файл (`LB-5\MaxVoronoy\patterns.cpp`) 

- За допомогою середовища зробіть commit цьому файлу
Обов'язково опішить коментар, що зроблено.

- Перевірити актуальність вашого локального репозитарію  

Треба впевнитись, що ваші зміни не конфліктують з віддаленими, для цього ще раз виконуємо команду `pull` 
([дивись](../LB-1/README.md) лабу #1).

- Перемістити локальні зміни на віддалений репозитарій.
Спробувати виконати команду `push` (конфліктів, скоріш за все, не повинно бути).
